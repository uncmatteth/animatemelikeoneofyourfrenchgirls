# The job

Make a scene in which recognizable people do understandable things in one
consistent place. The reference image establishes identity, palette, materials
and composition. The source script establishes why actions happen and when
objects change. Code is the moving set, not a replacement for either authority.

- Use detailed source art or approved character models. Preserve faces, hair,
  costumes, silhouettes and meaningful marks. Changing the renderer does not
  authorize redesigning characters.
- Separate a painted character into clean overlapping layers only when hidden
  areas are properly filled. A torso cannot retain a second copy of its moving arm.
- Keep a joint hierarchy and explicit hand/prop contact anchors. Track left and
  right hands anatomically. Rope endpoints attach to identified anchors.
- Speaking uses the speaker's mouth and expression; listeners react. Check actual
  audio intervals. A mouth bob driven by music is not dialogue synchronization.
- Reuse the same set and prop instances across shots. Show state transitions:
  closed → touched → activated → open. A camera change cannot move the wheel,
  erase a ladder, restore a broken beam or import an unexplained person.
- Camera movement serves action. Include anticipation, contact, load and settle.
  Walking needs planted feet and a shifting body; pulling needs visible tension.
- Preserve the authored look. Depth, fog, sparks and animated light are supporting
  effects and cannot substitute for character acting.
- Title cards need readable typography, enough hold time and deliberate movement
  connected to the story's visual language. Keep title timing separate from speech.
- Reuse the exact dialogue; add only the pauses required for visible actions.
  Record any timeline insertion explicitly. Never silently accelerate voices.
- Every correction must be carried into subsequent shots and reused scenes.

The Cutaway method contributes reference comparison, measurable proportions,
named parts/anchors, deterministic rendering, early review and one sound/picture
clock. It does not supply production-ready human animation or infer hidden views.
